# Old School Manager – Aggiornamenti

Qui ci sono solo i programmi di installazione (setup) di **Old School Manager**, nella sezione **Releases**.

- Il programma, all'avvio, controlla da solo se c'è una versione nuova e propone di aggiornarsi.
- Questo repository non contiene codice né dati: database, ricevute e dati degli iscritti restano sul PC della palestra.
